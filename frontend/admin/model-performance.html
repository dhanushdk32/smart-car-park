Input Feature Engineering & Transformation Pipeline
Features extracted from datetime parameters and weather metadata
Feature Name Data Type Preprocessing Transformation Domain / Value Range Role in Decision Boundary
area Categorical OneHotEncoder(handle_unknown='ignore') City Center Parking, Mall Parking, Theatre Parking Captures baseline facility capacity and core demand volume
hour Integer Numeric Pass-through / Scaler 0 – 23 (24-Hour Military Format) Primary driver for diurnal traffic and morning/evening rushes
minute Integer Numeric Pass-through / Scaler 0 – 59 Fine-grained granularity for quarter-hour arrival shifts
day_number Integer Numeric Pass-through 1 – 31 (Calendar Day of Month) Captures monthly pay-cycles and mid-month variation
day_of_week Categorical OneHotEncoder Monday through Sunday Differentiates high-intensity weekdays vs weekend shopping
month Categorical / String OneHotEncoder January through December Accounts for seasonal travel, holidays, and weather seasons
is_weekend Boolean / Integer Binary Flag (0 / 1) 0 = Weekday, 1 = Weekend Strong split separating commercial rush vs retail leisure
is_holiday Boolean / Integer Binary Flag (0 / 1) 0 = Regular Day, 1 = Public Holiday Predicts abnormal leisure peaks and office vacancy
weather Categorical OneHotEncoder Clear, Rainy, Foggy, Cloudy Adjusts for modal split (e.g. driving during precipitation)
